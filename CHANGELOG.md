# Changelog

## 0.1.0

- Initial native Hermes release of Mnemosyne Dashboard.
- Ship the dashboard tab, FastAPI plugin router, and React frontend bundle.
- Include overview, today, memories, graph, visualiser, context bank, history, and settings views.
- Add read-only browsing, diagnostics, and optional admin maintenance controls.
- Thanks to [Wysie/mnemosyne-dashboard](https://github.com/Wysie/mnemosyne-dashboard) for the original dashboard foundation and [AxDSan/mnemosyne](https://github.com/AxDSan/mnemosyne) for the Hermes integration path that this plugin builds on.
